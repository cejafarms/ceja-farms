# /images — photo slots

Drop photos in this folder using the **exact filenames** below and they replace the
labelled placeholders automatically — no code changes needed.

Save as JPG (quality ~85), sRGB. Match the **aspect ratio** so nothing crops oddly;
the pixel sizes are recommended targets.

## Logo

`logo.png` (700 × 195) is generated from the `logo.png` in the project root. The
source art is a dark plaque with fine cream linework, which disappeared against the
black nav bar, so the delivered file is recoloured: the linework is mapped to cream
(#F5F0E6) with the near-black plaque fill dropped to transparent, and the strokes
thickened slightly so it stays legible at the header's 62px height.

If you replace the source art, that recolour has to be redone — otherwise a dark-on-dark
logo will vanish into the header again.

---

Service-card and gallery photos are wide letterbox crops — crop them yourself rather
than letting the browser decide, so the important part of the frame survives.
